# Gamma

Gamma is the single sign-on authorization server for the IT student division at
Chalmers in Gothenburg. It lets members use one account to sign in to the division’s
services and manages their access through shared account and group information.

## Technology

Gamma is built with Kotlin and Spring Boot, using Spring libraries for security,
sessions, and authorization-server functionality. Pages are rendered on the server
in Kotlin, with HTMX for interactive updates.
